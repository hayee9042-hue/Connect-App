# JQ Hide Show

A small UI demo using jQuery and Bootstrap to toggle between Sign Up and Log In forms.

## What it shows
- `jQuery` click events
- `.hide()` / `.show()` for switching forms
- `Bootstrap` layout and buttons
- CSS animation for rotating images

## How to use
1. Open `index.html`.
2. Click `Already have an account?` to show Log In.
3. Click `Don't have an account?` to show Sign Up.
